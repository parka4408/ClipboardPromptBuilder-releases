# ClipboardPromptBuilder

文字列・Excelの表・画像を集め、AIチャットへ渡すプロンプトを作るWindowsアプリです。アプリ自身はAIへの送信や外部通信を行いません。

## ダウンロードと起動

1. このリポジトリの **Releases** を開き、`ClipboardPromptBuilder-<版>-net48-anycpu.zip` を取得します。GitHubが自動表示する「Source code」はアプリの配布ZIPではありません。
2. ZIP全体をローカルのフォルダーへ展開します。
3. 展開したフォルダーの `ClipboardPromptBuilder.exe` を起動します。DLLや設定ファイルも同じ場所に残してください。

実行には.NET Framework 4.8以降の互換ランタイムが必要です。Visual Studio・Git・Excelのインストールは必須ではありません。Windows 11 / x64で動作を確認しています。AnyCPUはビルド設定であり、すべてのOS・CPUでの動作を保証するものではありません。実行ファイルへの電子署名は付与していません。

会社のPCでは、会社が認めた取得・配置・実行手順に従ってください。起動が制限された場合は管理担当者に確認してください。

## 基本操作

1. 「収集開始」を押し、ほかのアプリで文字列・表・画像をコピーします。文字列は候補欄へ手入力することもできます。
2. 候補と識別名を確認して「登録」を押します。コピーだけでは登録されません。
3. 「編集へ」で文章を入力し、登録した行を並べ替えます。「定型」から文章テンプレートも使えます。
4. 「出力を見る」で本文を確認します。専用コピーボタンは自動検査後に有効になります。「確認」対象は該当箇所を画面内に表示し、「禁止」対象は編集して解消します。
5. 本文・画像をコピーし、利用先へ手動で貼り付けます。一括コピー後は本文と画像がそろっているかを確認してください。

画像は登録前・登録後に矩形で黒塗りできます。画像内の文字は自動検査しません。Excelの数式は、コピー内容に対応する数式入りXMLがある場合だけ追加取得できます。検査ルールによる検知は、機密情報がないことを保証するものではありません。

各テキスト欄の範囲選択によるCtrl+Cは検査状態によらず利用できます。専用コピーボタンの検査条件とは異なります。

## 設定・ルール・テンプレート

「…」メニューから各管理画面を開きます。ライト／ダーク、自動判定、自動名の接頭辞を設定でき、ルールとテンプレートは追加・編集・インポート・エクスポートできます。

更新しても保存済みのルールやテンプレートは自動で置き換わりません。同梱の `practical-rules.cpbrules` と `standard-templates.cpbtemplates` は各画面のインポートから追加・更新できます。

## 保存する情報

作成中の本文・素材・画像は自動保存しません。終了すると失われます。設定・ルール・テンプレートはWindows利用者別に保護して保存します。

保存先は `%LOCALAPPDATA%\ClipboardPromptBuilder` です。診断ログは `Logs`、設定は `Settings`、テンプレートは `Templates` にあります。通常の診断ログにコピー原文は含みません。**DebugをONにした間は、取得した文字列・HTML・Excel形式の原文とメタデータがローカルログに残ります。** Debugは起動時OFFです。ログを共有するときは内容を確認してください。

## 更新と終了

更新時はトレイの「終了」でアプリを閉じ、新版ZIPを別フォルダーに展開して起動します。自動更新はありません。同じWindows利用者の設定は引き継がれます。画面を閉じるだけではトレイに常駐します。

## 配布ファイルの確認

ReleaseにはZIPのSHA-256ファイルを添付します。ZIP内の `SHA256SUMS.txt` は展開後の各ファイルのハッシュです。ハッシュはファイルの一致を確認するためのもので、電子署名ではありません。

## ソースからビルド・改修する

Releasesの `ClipboardPromptBuilder-<版>-source.zip` を取得してください。Visual Studio 2022の「.NET デスクトップ開発」と.NET Framework 4.8 Developer Pack、およびNuGetのパッケージ取得環境が必要です。展開後のREADMEにビルド・テスト手順があります。

このリポジトリのGit履歴は配布案内だけを扱います。GitHubが自動表示する「Source code」はアプリのソースZIPではありません。アプリのソースは上記の添付ファイルとして提供し、開発履歴・個人設定・ログは含めません。
